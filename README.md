## 先分清两件事：能不能装上，和能不能跑动

搜索「Stable Diffusion云部署」的人，很多卡在第一步的认知上：部署成功不等于出图流畅。看一眼各家教程的底层的资源配置就明白了——AWS 的官方模板把方案部署到 G4dn GPU 实例，阿里云 PAI-EAS 底层是 GPU 资源，AutoDL 干脆就是直接租显卡，华为云的 Serverless 方案背后调的也是 GPU 算力。

一台没有 GPU 的便宜 VPS，WebUI 理论上装得上去，但纯 CPU 推理出一张图可能要等上几分钟甚至更久，实际没法用。显存方面，SD 1.5 这类基础模型对硬件比较宽容，8GB 显存的卡就能跑得比较顺；SDXL 这类更大的模型，12GB 以上才不憋屈。选方案时先看这一条，再谈价格。

## 四种主流部署形态，一小时成本差多少

从全自动托管到纯租卡，目前的部署形态大致四种，成本跨度很大，先看表：

| 部署形态 | 代表方案 | 计费参考 | 适合谁 |
| --- | --- | --- | --- |
| 云厂商一键模板 | AWS 通过 CloudFormation 部署到 G4dn 实例，内置 SD 1.5 模型 | 教程口径：1 小时内销毁资源，花费不超过 1 美元 | 有 AWS 账号、想在海外区快速验证的开发者 |
| 企业级托管服务 | 阿里云 PAI-EAS，分单机版、集群版、API 版三种形态 | 最低规格 60 分钟不超过 15 元 | 企业用户：多用户隔离、GPU 集群调度、账单拆分 |
| GPU 租用平台 | AutoDL 这类算力市场，选卡选镜像直接开机 | A5000 约 1.18 元/小时 | 预算敏感、按小时玩的个人用户 |
| Serverless 按量 | 华为云应用中心的 AI 绘画模板，一键部署 FunctionGraph | 按调用时间和次数计费，官方称最多可省 40–90% | 偶尔画几张、担心资源闲置浪费 |

价差有它的道理。AutoDL 那 1.18 元买的是一张裸卡加现成镜像，调度、运维、存储都自己操心；PAI-EAS 的 15 元买的是前后端分离改造、多用户调度、用户隔离和账单拆分这些企业级能力，还带自研的 ModelZoo 插件加速开源模型下载。你是一个人玩，为用不上的调度能力付费就有点冤了。

还有一个容易被忽略的隐藏成本：存储。阿里云函数计算那套部署方案的教程评论区里，有用户反馈 NAS 存储会持续产生小额费用，一个月攒到十几块。Serverless 方案听着「不用不花钱」，但挂在上面没删的模型和图片照样计费，用完记得清理。

## 在 Vultr 上把 WebUI 跑起来

整体路径和 AutoDL 那类教程差不多：选卡、开机、装 WebUI，区别是这台机器完全归你管。流程大致六步：

1. 注册账号，确认想要的 GPU 型号在目标数据中心有货——GPU 型号是按区域上架的；
2. 部署一台 Cloud GPU 实例，选好区域和系统镜像（Ubuntu 就够用），确认是按小时计费；
3. SSH 进实例，装好 Python 环境和显卡驱动依赖；
4. 拉取 AUTOMATIC1111 的 stable-diffusion-webui 项目——各家教程用的都是同一个 WebUI，再下载一个 Checkpoint 模型，SD 1.5 官方模型就能起步；

6. 用完先做一件事：处理计费。

第 6 步值得单独提醒：**停机不等于停费**。Vultr 的实例关机后一般仍按原费率计费，长期不用就直接销毁，想保留环境就打快照或挂块存储。模型文件动辄几个 GB，重装要重新下载，这个时间成本也要算进你的使用方式里。

## 几个高频问题

### 云部署 Stable Diffusion 一个月大概花多少钱？

取决于使用强度。按每天出图 1 小时算：AutoDL 的 A5000 约 35 元/月；AWS 按教程口径一小时不超过 1 美元，同强度一个月大致 20–30 美元；Vultr 的 Cloud GPU 按 1–3 美元/小时估算，一个月 30–90 美元，卡的性能也高一档。偶尔画几张的轻度用户，Serverless 按调用计费最省。

### 没有 GPU 的云主机也能部署吗？

能装，不能用。CPU 推理出一张图按分钟计，等你调好提示词，一晚上可能就出了几张图。真想省钱的正确姿势是租便宜档的卡，而不是租便宜的机器。

### 模型、插件和出图记录会一直保留吗？

不会自动保留。云实例随时可能销毁或重建：阿里云 PAI 方案靠挂载 NAS（性能型切换模型和出图更快），AutoDL 靠平台镜像，Vultr 用快照和块存储。无论哪家，满意的出图先下载到本地，这是最保险的习惯。

### 部署好之后对外提供服务要注意什么？

各家云厂商的方案免责声明口径一致：第三方开源模型的授权和安全责任在使用者自己。如果打算把部署好的 Stable Diffusion 做成对外的绘画服务，模型版权和生成内容合规都需要自行确认，这一步省不得。
